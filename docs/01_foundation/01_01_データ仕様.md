# データ仕様

Version: 2.0.0

---

# 1. 共通

* 文字コード UTF-8、改行 LF、ヘッダ行あり。
* 日付 `date` は `YYYYMMDD`、場コード `jcd` は2桁（3章）、レース番号 `rno` は 1〜12。
* レースのキーは `(date, jcd, rno)`、艇のキーはそれに枠番 `lane` を加えたもの。
* 値が無い項目は空欄。

---

# 2. 入力フォルダ（data/input/）

場ごと・月ごとにフォルダを作る。同じキーの行は上書きする（再取得しても重複しない）。

```text
data/input/{jcd}_{場名}/{YYYY-MM}/
  program.csv   出走表（前日までに分かる情報）
  preview.csv   直前情報（締切の30〜7分前に分かる情報）
  result.csv    結果（レース後）
  payout.csv    払戻金（レース後）
```

## 2.1 program.csv（キー：date, jcd, rno, lane）

| 列 | 内容 |
|---|---|
| deadline | 締切予定時刻（HH:MM） |
| grade | SG / PG1 / G1 / G2 / G3 / 一般 |
| title, race_type, distance | 節名・種別（予選・優勝戦 等）・距離（m） |
| lane | 枠番 1〜6 |
| racer_id, racer_name, racer_class, age, weight, branch | 登録番号・氏名・級別（A1/A2/B1/B2）・年齢・体重・支部（都道府県コード） |
| flying, late, avg_st | フライング数・出遅れ数・平均スタートタイミング |
| nat_win, nat_2r, nat_3r | 全国勝率・2連対率・3連対率 |
| loc_win, loc_2r, loc_3r | 当地勝率・2連対率・3連対率 |
| motor_no, motor_2r, motor_3r | モーター番号・2連対率・3連対率 |
| boat_no, boat_2r, boat_3r | ボート番号・2連対率・3連対率 |

## 2.2 preview.csv（キー：date, jcd, rno, lane）

| 列 | 内容 |
|---|---|
| wind, wind_dir, wave, weather, temp, water_temp | 風速・風向（コード）・波高・天候（コード）・気温・水温 |
| course | 展示の進入コース |
| ex_st | 展示のスタートタイミング |
| ex_time | 展示タイム |
| weight, weight_adj, tilt | 体重・調整重量・チルト |

## 2.3 result.csv（キー：date, jcd, rno, lane）

| 列 | 内容 |
|---|---|
| technique | 決まり手（コード） |
| course, st | 本番の進入コース・スタートタイミング |
| place | 着順コード（1〜6が着順。7以上は失格・欠場、14はフライング） |
| racer_id | 登録番号 |

## 2.4 payout.csv（キー：date, jcd, rno, bet_type, combo）

| 列 | 内容 |
|---|---|
| bet_type | win（単勝）/ place（複勝）/ exacta（2連単）/ quinella（2連複）/ wide（拡連複）/ trifecta（3連単）/ trio（3連複） |
| combo | 組合せ（`1-2-3`。2連複・3連複・拡連複も `-` 区切り） |
| payout | 100円あたり払戻金（円） |

コード値の意味は Boatrace Open API のコード表（https://boatraceopenapi.github.io/api/v1/codes.md）に従う。

# 4. 出力

| ファイル | 内容 |
|---|---|
| data/output/backtest_report.json | 検証結果（04_02） |
| data/output/backtest_ledger.csv | 確認期間に買った買い目と払戻（04_02） |
| data/output/model.json | 運用モデル（確率モデル・想定オッズモデルの係数、購入ルール） |
| data/predictions/YYYYMMDD.csv | 当日の予想（04_01 6章） |
| data/dashboard/run_status.json | 自動実行の履歴（直近50件） |
| data/dashboard/fetched_days.txt | 取得済みの日（再取得しない） |
