# データ仕様

Version: 1.0.0

---

# 1. 共通

* 文字コード UTF-8、改行 LF、ヘッダ行あり。
* 日付 `date` は `YYYYMMDD`、場コード `jcd` は2桁（3章）、レース番号 `rno` は 1〜12。
* レースのキーは `(date, jcd, rno)`。

---

# 2. 入力フォルダ（data/input/）

場ごと・月ごとにフォルダを作る。

```text
data/input/{jcd}_{場名}/{YYYY-MM}/
  program.csv   出走表（番組表）
  result.csv    競走成績
  payout.csv    払戻金
  odds.csv      確定オッズ
```

同じキーの行は上書きする（再取得しても重複しない）。行は日付・レース番号順に並べる。

## 2.1 program.csv（キー：date, jcd, rno, lane）

| 列 | 内容 |
|---|---|
| date, jcd, rno | レース |
| grade | SG / PG1 / G1 / G2 / G3 / 一般（開催一覧の表示による。取れない場合は空） |
| meet_title | 節名 |
| race_type | 種別（予選・一般・準優勝戦・優勝戦 等） |
| distance | 距離（m） |
| deadline | 締切予定時刻（HH:MM） |
| lane | 枠番（艇番）1〜6 |
| racer_id, racer_name, age, branch, weight, racer_class | 登録番号・氏名・年齢・支部・体重・級別（A1/A2/B1/B2） |
| nat_win, nat_2r | 全国勝率・全国2連対率 |
| loc_win, loc_2r | 当地勝率・当地2連対率 |
| motor_no, motor_2r, boat_no, boat_2r | モーター・ボートの番号と2連対率 |

## 2.2 result.csv（キー：date, jcd, rno, lane）

| 列 | 内容 |
|---|---|
| date, jcd, rno, race_type, distance | レース |
| weather, wind_dir, wind_m, wave_cm | 天候・風向・風速・波高 |
| lane, racer_id | 艇 |
| finish | 着順（1〜6）。失格・欠場等は公式の記号（F, L, K0, S0 等）をそのまま |
| motor_no, boat_no, exhibition, course, st, race_time | モーター・ボート・展示タイム・進入コース・スタートタイミング・レースタイム |

## 2.3 payout.csv（キー：date, jcd, rno, bet_type, combo）

| 列 | 内容 |
|---|---|
| bet_type | win（単勝）/ place（複勝）/ exacta（2連単）/ quinella（2連複）/ wide（拡連複）/ trifecta（3連単）/ trio（3連複） |
| combo | 組合せ（例 `1-2-3`） |
| payout | 100円あたり払戻金（円） |
| popularity | 人気順（無い券種は空） |

## 2.4 odds.csv（キー：date, jcd, rno）

1レース1行。確定オッズ（レース後に公式サイトで表示される最終オッズ）。

| 列 | 内容 |
|---|---|
| fetched_at | 取得日時（JST） |
| win_1〜win_6 | 単勝 |
| ex_1-2 〜 ex_6-5 | 2連単30通り |
| tri_1-2-3 〜 tri_6-5-4 | 3連単120通り |

欠場を含む組合せ等で値が無い場合は空欄。

# 4. 出力（data/output/・data/predictions/）

| ファイル | 内容 |

| data/output/backtest_ledger.csv | 確認期間に買った買い目と払戻（04_02） |

| data/predictions/YYYYMMDD.csv | 当日の予想（04_01 6章） |
| data/dashboard/run_status.json | 自動実行の履歴（直近50件） |
