# 検証設計

Version: 2.0.0

---

# 1. 目的

期待値派の成績を、学習にもルール選びにも使っていない期間で正直に測る。

実装：`scripts/br/analysis/backtest.py`（`python -m br.main backtest`）

---

# 2. 期間

データの最新日から数えて

| 期間 | 既定 | 用途 |
|---|---|---|
| 学習 | 選定期間より前のすべて（約4年） | モデルの学習 |
| 選定 | 確認期間の前の6か月 | 購入ルールの選択 |
| 確認 | 最後の6か月 | 成績の確認（何の決定にも使わない） |

---

# 3. 手順

1. 学習期間だけで確率モデルと想定オッズモデルを学習する。
2. 選定期間で、購入ルールの候補を試す。

   | 券種 | EV 基準 | 想定オッズ上限 |
   |---|---|---|
   | 単勝 | 1.0・1.1・1.2・1.3・1.5・2.0 | 5・10・30倍 |
   | 2連単 | 同上 | 20・50・150倍 |
   | 3連単 | 同上 | 50・200・1000倍 |

   購入点数が300点以上の候補のうち、回収率が最も高いものを選ぶ。
3. 学習＋選定期間で学習し直し、2. のルールで確認期間を評価する（実際の払戻金で計算）。
4. 参考として、確認期間に「期待値を見ずに、確率の高い買い目を毎レース同じ点数」買った場合の成績も出す。
5. 運用用に、全期間で学習し直して data/output/model.json に保存する（ルールは 2. のもの）。

---

# 4. 出力

* backtest_report.json：期間・対数損失・全候補の成績・選んだルール・確認期間の成績
* backtest_ledger.csv：確認期間に買った買い目と払戻

---

# 5. 注意

* 候補を多く試すほど、選定期間の成績は偶然良く見える。だから確認期間で確かめる。
* 自動実行のたびに期間をずらして再計算する。
