# 期待値派モデル設計

Version: 1.0.0

---

# 1. 評価思想

「市場の見立て（オッズ）より実際に来やすい買い目」だけを買う。

```
期待値(EV) = 推定確率 × オッズ
```

EV が基準以上の買い目だけを買い、基準を満たす買い目が無いレースは見送る。

実装：`scripts/br/analysis/`

---

# 2. 券種

単勝・2連単・3連単を候補とし、どれを使うかは 04_02 の手順で選ぶ。
推定確率は3連単120通りの確率として求め、2連単・単勝の確率はその合計で求める。

---

# 3. 対象レース（dataset.py）

6艇がすべて出走し（成績の着順が6艇とも数字）、3連単オッズ120通りがそろい、
3連単の払戻が1通りだけのレース。欠場・不成立・特払い・同着のレースは対象外。

---

# 4. 推定確率（model.py）

## 4.1 市場の見立て

3連単オッズの逆数を合計1に正規化した値 `q(i,j,k)` とする（控除率を除いた確率）。

## 4.2 補正

3連単120通りに対する条件付きロジットで補正する。

```
score(i,j,k) = a × log q(i,j,k) + b1・x_i + b2・x_j
p(i,j,k)     = exp(score) / Σ exp(score)
```

* `a` が1より小さいと、人気の組合せは見立てほど来ず、穴目は見立てより来るという
  市場のクセを補正する。
* `x` は艇の特徴量をレース内で標準化したもの：級別（A1=3〜B2=0）・全国勝率・
  当地勝率・モーター2連対率・ボート2連対率。`b1` は1着、`b2` は2着に来る艇の補正。
* 実際の的中組合せの対数尤度を、L2正則化（強さ1.0、`b` のみ）つきニュートン法で最大化する。

---

# 5. 購入ルール（ev.py）

| 項目 | 内容 |
|---|---|
| 券種 | 単勝・2連単・3連単から1つ（04_02 で選ぶ） |
| 購入対象 | EV が基準以上、かつオッズが上限以下の買い目 |
| 1レースの上限 | EV の高い順に2点まで |
| 購入金額 | 1点100円 |

EV の基準とオッズ上限は 04_02 の候補から選ぶ。

---

# 6. 当日の予想（predictor.py）

```text
python -m br.main predict
```

* 締切まで2〜25分のレースについて、発売中のオッズ（3連単・2連単・単勝）を取得し、
  運用モデル（data/output/model.json）と購入ルールで EV を計算する。
* 結果を data/predictions/YYYYMMDD.csv に1レースずつ追記する
  （購入：買い目ごとに1行。見送り：EV が最も高い買い目を1行）。一度予想したレースは再予想しない。
* 番組表がまだ無ければ、その日の番組表を取得してから予想する。
* 収支は、この記録どおりに買ったものとして、確定後の払戻金（payout.csv）で計算する。
  予想時点のオッズは確定オッズと異なるため、検証（確定オッズで計算）より
  正直な成績になる。
