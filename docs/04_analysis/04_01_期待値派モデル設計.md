# 期待値派モデル設計

Version: 2.1.0

---

# 1. 評価思想

「実際に来る確率に比べて、配当が高すぎる買い目」だけを買う。

```
期待値(EV) = 推定確率 × 想定オッズ
```

EV が基準以上の買い目だけを買い、基準を満たす買い目が無いレースは見送る。

オッズの履歴を正規に自動取得できる入手先が無いため（00_要件定義 2章）、オッズの代わりに
「その買い目が的中したときに付く払戻」を過去の実績から推定した**想定オッズ**を使う。

実装：`scripts/br/analysis/`

---

# 2. 券種

単勝・2連単・3連単を候補とし、どれを使うかは 04_02 の手順で選ぶ。
推定確率は3連単120通りの確率として求め、2連単・単勝の確率はその合計で求める。

---

# 3. 対象レース（dataset.py）

出走表が6艇そろい、6艇すべてが1〜6着に入り（失格・欠場なし）、3連単の払戻が
1通りだけのレース。

---

# 4. モデル（model.py）

## 4.1 艇の特徴量

* 枠番（6号艇を基準とするダミー5個）
* 場×号艇の強さ（3個）：その場のその号艇の過去の1着率・2着以内率・3着以内率が、全国平均から
  どれだけずれているか（ロジットの差）。イン有利の度合いは場によって大きく違う（例：戸田は1号艇が弱い）。
  率はそのレースの月より前の結果だけで数え、開催が少ないうちは全国平均に寄せる（300レース分）。
  運用時は全期間の数を model.json の venue_lane に保存して使う。
* 天気（4個）：直前情報の風速・波高を、1号艇だけに掛けたもの（in）と、号艇の外側ほど大きくなる値
  （1号艇 -1〜6号艇 +1）に掛けたもの（lane）。レース全体で同じ値なのでそのままでは効かないため。
* レース内で標準化した数値：級別（A1=3〜B2=0）、全国勝率・2連対率、当地勝率・2連対率、
  モーター2連対率、ボート2連対率、平均ST、フライング数、体重、展示タイム、展示ST、展示の進入コース
* 欠損はレース内の平均（標準化後は0）とする。
* 結果（本番の進入・ST・気象）は使わない（レース前には分からないため）。

## 4.2 推定確率

3連単120通りに対する条件付きロジット。

```
score(i,j,k) = b1・x_i + b2・x_j + b3・x_k
p(i,j,k)     = exp(score) / Σ exp(score)
```

b1〜b3 は1〜3着に来る艇の特徴の重み。実際の的中組合せの対数尤度を、
L2正則化（強さ1.0）つきニュートン法で最大化する。

## 4.3 想定オッズ

券種ごとに、的中した組合せの log(払戻) を、その組合せの特徴量（着順位置ごとの艇の特徴量）で
リッジ回帰（強さ1.0）し、`exp(予測値 + 残差の分散/2)` を想定払戻（100円あたり）とする。
想定オッズ = 想定払戻 ÷ 100。

「的中したときの払戻」の平均を推定しているので、`推定確率 × 想定オッズ` がそのまま期待値になる。
世間（オッズ）は主に級別・勝率などで買うため、展示タイム・場の特徴・天気でそれと違う見立てが
できた買い目が割安候補になる。

# 5. 購入ルール（ev.py）

| 項目 | 内容 |
|---|---|
| 券種 | 当面は単勝のみ（backtest.BET_TYPES。2連単・3連単に戻すこともできる） |
| 購入対象 | EV が基準以上、かつ想定オッズが上限以下の買い目 |
| 1レースの上限 | EV の高い順に2点まで |
| 購入金額 | 1点100円 |

---

# 6. 当日の予想（predictor.py）

```text
python -m br.main predict
```

* 当日の出走表・直前情報を、約10分間隔で更新される統合API
  （`https://boatraceopenapi.github.io/api/v1/{YYYY}/{YYYYMMDD}.json`）から取得する。
  旧 `{種類}/v2/today.json` の直前情報は1日2〜3回しか更新されず、締切前に展示タイムが手に入らないため。
* 展示タイムが6艇そろい、締切まで1分以上あってまだ予想していないレースについて、運用モデル
  （data/output/model.json）と購入ルールで EV を計算する（06_01 4章のとおり5分ごとに確認）。
  締切までに直前情報が出なかったレースは予想しない。記録の lead_min は予想した時点の締切までの分。
* 結果を data/predictions/YYYYMMDD.csv に追記する（購入：買い目ごとに1行。
  見送り：EV が最も高い買い目を1行）。一度予想したレースは再予想しない。
* 収支は、この記録どおりに買ったものとして、確定後の払戻金（payout.csv）で計算する。

---

# 7. 限界

* 実際のオッズを見ていないため、本当に割安かどうかは確認できない。想定オッズは
  「その組合せが的中したときの平均的な払戻」であり、そのレースの実際のオッズとはずれる。
* 収支は実際の払戻金で計算するので、成績そのものは正直な数字になる。
* 実際のオッズを正規に取得できる手段ができたら、市場の見立てを加えたモデルに切り替える。
