# 試走1位の1号艇（記録用ルール）

Version: 1.0.0

---

# 1. 目的

期待値モデル（04_01）とは別に、単純なルール「試走（展示タイム）の良い1号艇を買う」を
全場・全レースで記録し、場ごとの得意不得意をこれから先の成績で確かめる。

実装：`scripts/br/analysis/inside_ex.py`

---

# 2. 対象レース

1. 6艇すべての展示タイム（0より大きい値）があるレース。
2. 各艇の「補正タイム」＝展示タイム −（その場・その号艇の平均展示タイム）。
3. 1号艇の補正タイムが6艇の中で最小（同タイムを含む）のレースを対象とする。

号艇ごとの平均は、記録開始日（START = 2026-11-25）より前のデータだけで計算し、以後は固定する。
記録開始以降の成績が平均の計算に混ざらないようにするため。

# 3. 買い方

対象レースで1号艇の単勝と複勝を1点100円ずつ。払戻金は実際の確定払戻（payout.csv）を使う。
払戻が確定していないレースは集計しない。

# 4. 集計

全体と場ごとに、記録開始以降と全期間の、点数・的中数・回収率・収支。
全期間の値は平均の計算に使ったデータを含むので参考値とする。

# 5. 参考：導入前の確認（2026-11-24）

直近6か月（2026-05-24〜11-23、平均はそれより前で計算）：単勝 回収率96.0%、複勝97.3%。
場を前の期間の成績で選ぶと、単勝は直近6か月で良くならず、複勝の上位3場（尼崎・福岡・江戸川）は102.4%（613点）。
場の差は運でも出るため、記録開始以降の成績で判断する。
