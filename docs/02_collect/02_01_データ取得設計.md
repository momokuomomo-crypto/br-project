# データ取得設計

Version: 1.0.0

---

# 1. 目的

公式サイトから番組表・競走成績・払戻金・確定オッズを取得し、
01_01 の入力フォルダ（data/input/）を作成する。

実装：`scripts/br/collect/`

---

# 2. アクセス方針（client.py）

* 実行場所は日本の回線（00_要件定義 2章）。海外からの拒否を回避する工夫
  （送信元の偽装等）はしない。
* 1プロセスあたり1秒に1回までのペースでアクセスする。
* 一時的なエラー（接続失敗・5xx・429）は待ち時間を倍にしながら最大4回再試行する。
  404 は「データ無し」として扱う。

---

# 3. 番組表・競走成績（lzh_parsers.py）

公式の一括ダウンロード（1日1ファイル、LZH圧縮、Shift_JIS固定長テキスト）を使う。

| 種類 | URL |
|---|---|
| 番組表 | `https://www1.mbrace.or.jp/od2/B/{YYYYMM}/b{YYMMDD}.lzh` |
| 競走成績 | `https://www1.mbrace.or.jp/od2/K/{YYYYMM}/k{YYMMDD}.lzh` |

* 各行をNFKC正規化（全角数字・英字・空白を半角へ）してから正規表現で読む。
* 場ごとのブロック `{jcd}BBGN`〜`{jcd}BEND`（成績は `KBGN`〜`KEND`）の中で、
  レース見出し行（`{R}R … H{距離}m …`）に続く行を、そのレースの艇・払戻として読む。
* 番組表：艇の行から 01_01 2.1 の列を得る。締切予定時刻はレース見出し行から得る。
* 競走成績：着順の行から 01_01 2.2、払戻の行（単勝・複勝・2連単・2連複・拡連複・
  3連単・3連複）から 01_01 2.3 を得る。拡連複のように複数行にわたる払戻も読む。

# 4. 開催一覧・オッズ（odds.py）

| ページ | URL（`https://www.boatrace.jp/owpc/pc/race/`） | 用途 |
|---|---|---|
| 開催一覧 | `index?hd=` | 場ごとのグレード（`is-SG`・`is-G1b`・`is-ippan` 等のクラス名）と節名 |
| 3連単 | `odds3t?rno=&jcd=&hd=` | 120通り。列＝1着艇、行＝2着・3着（昇順）。各値の直前のセルの3着艇番と照合する |
| 2連単 | `odds2tf?rno=&jcd=&hd=` | 最初の表が2連単30通り（2番目の2連複は使わない） |
| 単勝 | `oddstf?rno=&jcd=&hd=` | 最初の表が単勝6通り（2番目の複勝は使わない） |

* 値は `td.oddsPoint`。数値以外（欠場等）は空欄とする。
* 過去のレースでもページは確定オッズを表示する（2020年分まで確認済み）。
* 表の形が想定と違う場合は例外とし、そのレースを失敗として記録する
  （推測で埋めない）。

# 5. 確定済みレースの収集（collector.py）

1日ごとに、開催一覧 → 番組表 → 競走成績 → 成績のある各レースのオッズの順に取得する。
odds.csv に既にあるレースのオッズは取得しない（中断しても続きから再開できる）。
1レースの失敗で全体を止めない。

```text
python -m br.main yesterday                         # 直近7日（新しい日から）
python -m br.main collect --from YYYY-MM-DD --to YYYY-MM-DD [--no-odds] [--pages odds3t,odds2tf]
```

（実行ディレクトリは `scripts/`）

---

# 6. 過去データの取り込み（backfill.py）

```text
python -m br.main backfill --from YYYY-MM-DD --to YYYY-MM-DD [--no-odds] [--budget-min 分]
```

* 新しい月から古い月へ1か月ずつ取得し、1か月ごとに commit・push する。
* `--budget-min` を超えたら終了し、次回は続きから取得する。
* 量の目安：1年あたり約5.4万レース。オッズは1レース3ページ（1秒1回で約45時間／年）。

取り込みの順番：

1. 番組表・成績を5年分（`--no-odds`、1日2ファイルのため短時間）
2. 確定オッズを直近2年分
3. 確定オッズを残り3年分

---

# 7. 調査用

```text
python -m br.main sample --date YYYYMMDD   # samples/ に生テキスト・HTMLを保存
```
