# データ取得設計

Version: 2.1.0

---

# 1. 目的

出走表・直前情報・結果・払戻を取得し、01_01 の入力フォルダ（data/input/）を作成する。

実装：`scripts/br/collect/`

---

# 2. データ元

Boatrace Open API（非公式。https://github.com/boatraceopenapi ）。
GitHub Pages で配信される1日1ファイルのJSONで、認証不要・自動取得を前提に公開されている。

| 種類 | URL |
|---|---|
| 出走表 | `https://boatraceopenapi.github.io/programs/v2/{YYYY}/{YYYYMMDD}.json` |
| 直前情報 | `https://boatraceopenapi.github.io/previews/v2/{YYYY}/{YYYYMMDD}.json` |
| 結果・払戻 | `https://boatraceopenapi.github.io/results/v2/{YYYY}/{YYYYMMDD}.json` |
| 当日分（予想用） | `https://boatraceopenapi.github.io/api/v1/{YYYY}/{YYYYMMDD}.json`（出走表・直前情報・結果をまとめた新API。約10分間隔で更新、2026-01以降。旧 v2 は Deprecated で、直前情報の当日更新は1日2〜3回） |

* 2020年以降のデータがある（2026-11-24確認）。オッズは含まない。
* 公式サイトではないため、欠損・誤りがありうる。
* 公式サイト（boatrace.jp・mbrace.or.jp）はプログラムからのアクセスを拒否するため使わない（00_要件定義 2章）。

---

# 3. 取得・変換（openapi.py）

* 1秒に1回までのペースで取得する。404 は「データ無し」。一時的なエラーは待ち時間を倍にしながら最大4回再試行する。
* JSON を 01_01 2章の列へ変換する。級別・グレードはコード表で文字に変換する。
* 払戻は券種ごとの配列（組合せ・金額）を payout.csv の行にする。金額が無いもの（返還等）は除く。

---

# 4. 収集（collector.py）

```text
python -m br.main yesterday                         # 直近7日（取り直す）
python -m br.main collect --from YYYY-MM-DD --to YYYY-MM-DD
```

（実行ディレクトリは `scripts/`）

* 1日ごとに出走表・直前情報・結果を取得して保存する。
* 結果が取れた日（または3日以上前で非開催の日）は data/dashboard/fetched_days.txt に記録し、
  次回からは取得しない（`yesterday` は直近7日を毎回取り直し、後からの修正を反映する）。

---

# 5. 過去データの取り込み（backfill.py）

```text
python -m br.main backfill --from YYYY-MM-DD --to YYYY-MM-DD [--budget-min 分]
```

* 新しい月から古い月へ1か月ずつ取得し、1か月ごとに commit・push する。
* 時間上限を超えたら終了し、再実行すれば続きから取る。
* 5年分で約5,500ファイル（1秒1回で約1.5時間）。
