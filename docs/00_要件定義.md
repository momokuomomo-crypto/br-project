# BR_Project 要件定義

Version: 2.0.0

---

# 1. 目的

競艇（ボートレース）の出走表・直前情報・結果・払戻を自動で集め、
「期待値派」の考え方で予想・検証し、結果を公開ダッシュボードで確認できる
ようにする。競馬版（kb-project）と同じ「データをpushすると分析が走り、
ダッシュボードが更新される」仕組みとする。

---

# 2. 決定事項（2026-11-23〜24）

| 項目 | 内容 |
|---|---|
| 対象レース | 全24場・全グレード（SG・PG1・G1・G2・G3・一般） |
| リポジトリ | `momokuomomo-crypto/br-project`（公開。Actionsの利用時間に上限が無いため） |
| ダッシュボード | 本リポジトリの GitHub Pages（https://momokuomomo-crypto.github.io/br-project/） |
| 過去データ | 全24場・場ごとに過去5年分（2021-11-24〜） |
| データ元 | Boatrace Open API（非公式、GitHub Pages で配信される静的JSON。自動取得を前提に公開されている） |
| 実行場所 | すべて GitHub のクラウド（ubuntu-latest）。利用者のPCは不要 |

公式サイト（boatrace.jp・mbrace.or.jp）は、ブラウザ以外のプログラムからのアクセスを
HTTP 403 で拒否する（GitHub のクラウドからも、利用者のPC（日本の回線）からも同じ。2026-11-24確認）。
この拒否をすり抜ける取得（ブラウザの偽装等）はしない。そのため公式サイトからの自動取得はやめ、
自動取得を前提に公開されている Boatrace Open API を使う（2026-11-24、利用者の指示「別の場所から取ろう」）。

Boatrace Open API にはオッズが含まれない。オッズの履歴を正規に自動取得できる入手先は
見つからなかったため、期待値は「過去の払戻実績から推定した想定オッズ」で計算する（04_01）。

---

# 3. 買い方の考え方（期待値派）

* モデルが推定した的中確率と、オッズ（から見た確率）を比べ、
  `推定確率 × 想定オッズ` が基準以上（割安）のときだけ買う。
  想定オッズは、その組合せが的中したときの払戻を過去の実績から推定したもの。
* 毎レース買わない。割安な買い目が無いレースは見送る。
* 検証は、学習にもルール選びにも使っていない期間の成績で行う（04_02）。

# 4. システム構成

| 番号 | 設計書 | 責務 |
|---|---|---|
| 01 | 01_foundation/ | データ（CSV）の共通仕様 |
| 02 | 02_collect/ | データ元からの取得・変換・入力フォルダ作成 |
| 04 | 04_analysis/ | 期待値派のモデル・購入ルール・検証・当日予想 |
| 06 | 06_pipeline/ | 自動実行（GitHub Actions）とダッシュボード |

番号は競馬版にそろえている（03 Interface・05 Improvement に当たるものは現時点で持たない）。

---

# 5. 手作業

利用者の手作業は無い。収集・分析・予想・公開はすべて GitHub Actions で自動実行する。
