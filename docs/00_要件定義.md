# BR_Project 要件定義

Version: 1.0.0

---

# 1. 目的

競艇（ボートレース）の出走表・結果・確定オッズを公式サイトから自動で集め、
「期待値派」の考え方で予想・検証し、結果を公開ダッシュボードで確認できる
ようにする。競馬版（kb-project）と同じ「データをpushすると分析が走り、
ダッシュボードが更新される」仕組みとする。

---

# 2. 決定事項（2026-11-23〜24）

| 項目 | 内容 |
|---|---|
| 対象レース | 全24場・全グレード（SG・PG1・G1・G2・G3・一般） |
| リポジトリ | `momokuomomo-crypto/br-project`（公開。Actionsの利用時間に上限が無いため） |
| ダッシュボード | 本リポジトリの GitHub Pages（https://momokuomomo-crypto.github.io/br-project/） |
| 過去データ | 場ごとに過去5年分。番組表・成績は5年分、確定オッズは直近2年分を先に取り込み、残り3年分を追加で取り込む |
| 収集の実行場所 | 利用者のPC（日本の回線）を GitHub Actions の自前の実行マシン（self-hosted runner、ラベル `jp`）として使う |

公式サイト（boatrace.jp・mbrace.or.jp）は GitHub のクラウド実行環境（海外）からの
アクセスを拒否する（2026-11-23確認、HTTP 403）。拒否を回避する工夫はせず、
日本の回線から取得する。分析・ダッシュボード生成は公式サイトにアクセスしないため
クラウドで行う。

---

# 3. 買い方の考え方（期待値派）

* オッズから見た確率（市場の見立て）と、モデルが推定した確率を比べ、
  `推定確率 × オッズ` が基準以上（割安）のときだけ買う。
* 毎レース買わない。割安な買い目が無いレースは見送る。
* 検証は、学習にもルール選びにも使っていない期間の成績で行う（04_02）。

---

# 4. システム構成

| 番号 | 設計書 | 責務 |
|---|---|---|
| 01 | 01_foundation/ | データ（CSV）の共通仕様 |
| 02 | 02_collect/ | 公式サイトからの取得・解析・入力フォルダ作成 |
| 04 | 04_analysis/ | 期待値派のモデル・購入ルール・検証・当日予想 |
| 06 | 06_pipeline/ | 自動実行（GitHub Actions）とダッシュボード |

番号は競馬版にそろえている（03 Interface・05 Improvement に当たるものは現時点で持たない）。

---

# 5. 手作業

利用者の手作業は、PCを実行マシンとして使うためにPCの電源を入れておくことのみとする。
PCが止まっている間の収集・予想は行われず、次に動いたときに取りこぼし分
（直近7日）を収集する。

---

# 6. 未解決事項（2026-11-24）

公式サイト（boatrace.jp・mbrace.or.jp）は、ブラウザ以外のプログラムからのアクセスを
HTTP 403 で拒否する（GitHub のクラウドからも、利用者のPC（日本の回線）からも同じ）。
robots.txt は全許可だが、アクセス制御で自動取得を止めているため、これをすり抜ける
取得（ブラウザの偽装等）はしない。データの正当な入手方法が決まるまで、
収集・当日予想の定期実行（10_collect・11_predict）は停止する。
