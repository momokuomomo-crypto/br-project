# ダッシュボード設計

Version: 1.0.0

---

# 1. 目的

収集の状況、次のレースのおすすめ、集計開始からの収支を1枚のページで確認できるようにする。

# 2. 公開先

https://momokuomomo-crypto.github.io/br-project/ （本リポジトリの GitHub Pages）

# 3. 実装配置

`scripts/br/dashboard/`（data.py：集計、render.py：HTML生成）

```text
python -m br.main dashboard <出力先>
```

# 4. 表示内容（data.py）

## 4.1 次のレースのおすすめ

今日以降の予想（data/predictions/）の「購入」行：締切・場・R・グレード・買い目・
オッズ・推定確率・期待値。確定後は的中・不的中を表示する。判定したレース数と
購入ルールを併記する。無い場合は直近の予想日を表示する。

## 4.2 運用開始からの収支

予想記録の「購入」行を1点100円で買ったとして、確定した払戻金で計算する。
収支・回収率・点数・買ったレース数・的中数・累積収支の推移・月別。
実際の購入記録ではないことを明記する。

## 4.3 検証：学習に使っていない期間の成績

04_02 の確認期間の成績（同じ項目）と、期間・レース数、市場の見立てのままの場合の回収率。

## 4.4 データ収集状況

場ごとに、最初・最新の開催日、開催日数、成績のあるレース数、確定オッズのあるレース数と取得率。

## 4.5 自動実行の履歴

data/dashboard/run_status.json の直近10件。

# 5. 生成（render.py）

依存の無い1ファイルの index.html（CSS埋め込み、グラフはSVG）。ライト・ダーク両対応。
